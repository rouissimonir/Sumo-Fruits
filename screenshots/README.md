Capture the current TestFlight build on an iPhone, with the real play area untouched. Use these six moments:

1. First merge in career bout 1 — explain drag, launch, merge.

6. A real reward reveal — show Equip & Continue.

Keep each original capture. Add short copy, brand color and a frame around the capture without repainting the game area. Export opaque PNGs for the 6.9-inch and 6.5-inch iPhone slots at the exact dimensions accepted by App Store Connect. Check both sets at thumbnail size and on a phone before uploading.
