# Future art reference

The illustrated 3D store concepts in `marketing/screenshots/` and the older numbered files moved into `old-store-concepts/` are design references. They are not screenshots of the current game and must not be used as App Store product screenshots for the first release. The actual game uses procedural 2D Canvas characters. If the art style is upgraded later, use these concepts to guide a separate in-game art project after the market test.
